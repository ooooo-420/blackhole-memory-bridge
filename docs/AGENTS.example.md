# 專案入口

專案記憶在本資料夾的 `MEMORY.md`。開始工作時先讀它。

## 分支

分支是專案內的工作主題，存在 `branches/`：`INDEX.md` 是清單，每個分支一個檔案。它和聊天視窗無關，也不是 git 分支。

- 使用者要求開分支、切換、合併或封存時，直接做。
- AI 只在主題明確且需要持續處理，或工作已明顯偏離目前分支時主動建立，並告訴使用者。短暫離題只記待辦。
- 切換時，先把原分支的停點和待辦寫回，再讀目標分支。
- 每次變動都要同步更新 `INDEX.md`。

## 保存記憶

- 使用者確認的決策、完成的工作和實測結果，要寫回 `MEMORY.md`。
- 分清楚已確認、候選和未驗證。沒實測過的功能不要寫成可用。
- `.memory-bridge/log` 由 Hook 產生，不要手動修改。
