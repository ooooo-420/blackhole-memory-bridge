# Project entry

Project memory is in `MEMORY.md` in this folder. Read it when you start work.

## Branches

A branch is a work topic within the project, stored in `branches/`: `INDEX.md` is the list, and each branch has its own file. Branches are not chat windows or git branches.

- When the user asks to create, switch, merge or archive a branch, do it.
- The AI creates a branch on its own only when a topic is clear and needs ongoing work, or the work has clearly left the current branch, and it tells the user. A brief detour is only recorded as a to-do.
- When switching, write the current branch's stopping point and to-dos back first, then read the target branch.
- Update `INDEX.md` with every change.

## Saving memory

- Write decisions the user confirmed, completed work and test results back to `MEMORY.md`.
- Separate what is confirmed, proposed and unverified. Do not describe untested features as working.
- `.memory-bridge/log` is generated by hooks. Do not edit it by hand.
